# Rowlet Works

A small, working catalogue of interface and motion studies by Jianhao Cheng.

- **Form / Field:** original animated GLB and interactive browser viewer. Twenty-four objects, three formations, twelve seconds. Source: https://github.com/RowletCC/form-field
- **The Pass:** original restaurant-management interface concept with fictional data. Source: https://github.com/RowletCC/the-pass-ui

Both demos are included locally for a self-contained review. No account, purchase, external font, analytics or wallet is required. Previews load only when opened and unload when closed. Direct page links work without JavaScript.

These are independent AI-assisted studies, not shipped client projects or accepted commissions. Browser checks do not imply Unity, FBX, Unreal or console-controller compatibility.

## Run locally

From this directory: `python3 -m http.server 8911 --bind 127.0.0.1`.

Open `http://127.0.0.1:8911/`.

Screenshots in `assets/` were captured from the actual included demos. Three.js is distributed under its MIT license; see `studies/form-field/vendor/LICENSE-three.txt`. Source and validation details for each study remain in its directory.
